================================================================
  재고관리 프로그램 개발 명세 (exe)
================================================================


[ 기본 구조 ]

  - 철 소재 / 알루미늄 소재 탭 분리
  - 탭별 데이터 독립 관리 (품번 체계 동일, 소재만 다름)


----------------------------------------------------------------
[ 관리 데이터 ]
----------------------------------------------------------------

  소재    MD품번   아노다이징까지 완료된 소재
  완제품  MA품번   피팅 조립까지 완료된 제품
  피팅    SA품번   조립에 들어가는 부품 (BOM 기반)

  BOM     MA 1개 생산 시 필요한 SA품번별 수량 구성표
          (도면 기반 수작업 입력 데이터, 변경 가능해야 함)


----------------------------------------------------------------
[ 기능 1 ] 완제품 생산 등록
----------------------------------------------------------------

  입력   MA품번별 생산 수량

  처리
    - 소재(MD)  재고  → 생산 수량만큼 차감
    - 피팅(SA)  재고  → BOM 수량 × 생산 수량만큼 차감
    - 완제품(MA) 재고 → 생산 수량만큼 증가

  예시) MA000841 19개 생산 등록
    → MD000014  -19
    → SA000320  -38  (BOM 수량 2 × 19)
    → MA000841  +19


----------------------------------------------------------------
[ 기능 2 ] 납품 출고 (납품명세서 업로드)
----------------------------------------------------------------

  입력   납품명세서 엑셀 파일 (.xlsx)

  처리
    - 명세서 내 품번 기준으로 완제품(MA) 재고 차감
    - 철 소재 기존 방식과 동일하게 적용


----------------------------------------------------------------
[ 기능 3 ] 피팅 재고 실사 입력(수정 기능)
----------------------------------------------------------------

  입력   SA품번별 실재고 수량 직접 입력 기능

  처리
    - 입력한 수량으로 피팅 재고 덮어쓰기
    - 이후 생산 등록 시 자동 차감으로 추적


----------------------------------------------------------------
[ 기능 4 ] 재고 경고
----------------------------------------------------------------

  - 피팅(SA) 재고가 3개월 출고량 합계 이하로 떨어지면 경고 표시

----------------------------------------------------------------
[ 기능 5 ] 엑셀 출력
----------------------------------------------------------------

  - 현재 재고 현황 (소재 / 완제품 / 피팅) 엑셀 다운로드
  - 생산 이력 / 납품 이력 기간 지정 후 엑셀 다운로드
